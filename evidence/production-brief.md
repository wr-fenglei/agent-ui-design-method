# 十个来源对照稿的制作条件

下列内容整理自给十个来源的共同制作简报, 保留影响构图与归因的条件, 各来源作者可看到当时项目上下文, 本轮没有随机分配能否看到历史参考

| 固定项 | 原任务要求 |
|---|---|
| 设备与交付 | 1440 × 940 Mac Agent, Figma 原生可编辑, 使用英文产品文案 |
| 工作区和问题 | Quarry, RL-238, Duplicate checkout events |
| 订单与事实 | TEST-8072, checkout_complete, 09:41:12.083 首次确认, 09:41:12.516 网络重试 |
| 操作和结果 | 用户请求, Agent 工作与回复, 检查结果, 继续提问, 修补后 2 次重试产生 1 个事件, checkout-event.patch, Review patch |
| 参考来源 | 各自研究一种来源, 查官方页面或原始实现与第三方材料, 图库条目追到产品作者, 标记工具生成的已知关系 |
| 设计决定 | 采用有证据的产品构图, 自定区域位置与排版, 避免通用宣传首屏, 成排无关 KPI, 无任务用途的色块和标签 |
| 制作次序 | 先提交有出处的规范, 再编写本来源绘图函数, 在同一文档先发布规范后发布设计 |
| 共同工具 | 共用 Figma 原生绘图函数与基础字体别名, 允许单稿加载额外字体 |

用户在此前反馈中认可项目内 Linear 稿, 提出分割线应克制, 并要求参考 Linear, shadcn/ui, Untitled UI 的布局细节, 十个来源稿共用这些反馈, 简报未单独检验这项影响
