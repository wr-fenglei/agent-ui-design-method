# Apple 的 Mac 导航与工具栏

## Music 的贴边侧栏

[打开截帧, 1312 × 819 px](music-sidebar.jpg)

在 Home 选中行和下方的 Artists, Albums 几行之间对照背景, Home 用灰色圆角底标记当前位置, 下方几行则透出青色和粉色的专辑封面, 侧栏贴到窗口左, 上, 下边缘, Quarry 沿用贴边布局, 选中底和字重变化 [Quarry 选中行](../../examples/apple-glass/components/selected-finding.png)

图像出处为 Apple WWDC26 的 Platforms State of the Union, 会话 102 的 23:54, 制作时从 1920 × 1080 视频帧裁下完整应用窗口和周围的壁纸, 本目录保留历史截帧文件, 通过带时间的官方链接可以定位同一画面, 寻找同类应用可在 Apple Developer Videos 搜索 AppKit 或 sidebar, 选开能同时看到侧栏和后方内容的演示片段 [Music 23:54](https://developer.apple.com/videos/play/wwdc2026/102/?time=1434) · [Apple Developer Videos](https://developer.apple.com/videos/)

## Notes 的顶部工具组

[打开官方原图, 1198 × 846 px](notes-toolbar.png)

在画面上沿从左向右看, 列表, 表格和附件等编辑命令共用一块底面, 锁和搜索各有独立底面, 更多菜单在对应按钮下方展开, Notes 的正文仍有连续的深色背景, Quarry 取用同类命令成组的做法, 把上一个问题和下一个问题放在同一胶囊内 [Quarry 工具组](../../examples/apple-glass/components/previous-next.png)

图像出处为 Apple Human Interface Guidelines 的 Toolbars, 在 Best practices 的 More menu 段落查看 Standard 和 Compact 两张图, 切到深色外观可找到本文件对应的展开状态, 此 PNG 与 Apple 发布的深色 2× 资源逐字节相同, 可沿同页的紧凑状态对照空间收窄后的菜单内容 [Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars) · [官方深色 PNG](https://developer.apple.com/tutorials/images/com.apple.HIG/toolbars-notes-app-expanded-icons~dark@2x.png)

## 找对应的平台规范和组件

查材质时在 Materials 的 Liquid Glass 小节核对导航, 控件和正文各用什么材质, 查控件尺寸时从 Apple Design Resources 进入 macOS, 打开与目标版本对应的 UI Kit, 选同一外观和状态的工具组或侧栏行, 这两种入口分别提供使用建议和可检查的组件 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) · [Apple Design Resources 的 macOS 区域](https://developer.apple.com/design/resources/#macos)
