## 当前 Mac Agent 稿采用的组件关系

当前稿以常驻 Sidebar 和 SidebarInset 主工作区呈现发布审查, 所选任务的检查、依据和操作置于主工作区, 官方桌面页面中的 Drawer 是另一个交互状态的尺寸参考

- 侧栏保留任务和运行入口, 采用 32 px 行、16 px 图标、8 px 图文间距, 当前视图使用一次选中态
- 工具调用或产物使用表格与列表组织, 相邻行共享列轴, 选中条目的详情留在本稿 SidebarInset 内容区
- 状态同时给出图标和文字, 普通元数据使用次文字色, 确有状态语义的局部图标可以上色
- Agent 指令、消息或附件行沿用这组字体、内距、边线与焦点规则, 这些是本项目的组合决策

## 官网展示的可选状态

- 桌面示例点击 Cover page 可打开宽 384 px 的右侧 Drawer, 内容通高, 底部两个操作间距 8 px
- 表格 Target 和 Limit 两列采用右对齐的 64 × 32 px 数字编辑框, 当实际任务包含可编辑的数值时可采用, 普通文本行沿各自列轴排布
- 740 px 窄窗下点 Toggle Sidebar 可打开左侧 Sheet, 该行为是小窗导航参考

## 项目约束与验收

这些条件用于检查本项目的 Figma 导出图, 它们是对本稿的要求, 数值之外的视觉选择已与官网测量分别注明

| 检查点 | 失败条件 | 验收方式 |
| --- | --- | --- |
| 同级列表行线 | 前一行底边与后一行顶边重复绘制 | 同一 y 坐标只绘一条 1 px 行线, 在实图逐对检查相邻行 |
| 按钮、Badge、标签和图标 | 文字或图标贴近单侧, 组合中心偏离控件 | 图标框和文字行高框垂直中心差不超过 1 px, 居中按钮按图标加间隔加文字整体居中 |
| 状态用色 | 整个内容区铺提醒色, 单凭颜色表示状态 | 普通内容区使用白色或浅灰, 状态标记同时含文字, 有色区域限于对应图标或状态控件 |
| 表格对齐 | 同一列逐行变换起点, 行末控制被相邻文案覆盖 | 相同列共用同一水平锚点, 检查 100% 导出比例下所有行末操作完整可见 |
| 消息、动作与边界 | 时间、按钮箭头或结论穿出区块边界 | 检查右侧 24 px 工作区内距和输入/按钮自身的内容界限, 图标与文字节点无意外相交 |
