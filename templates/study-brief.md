# Mac Agent 设计简报

将方括号替换为项目事实, 多人独立出稿时共用同一份任务和选图记录, 为每份稿填入各自的设计方向

```text
产品与视口 = [工作区, 设备和尺寸]
用户要做的决定 = [当前问题, 阅读证据后的下一步操作]
固定事实 = [请求, 证据, Agent 结论, 验证结果, 当前审批状态和可用动作]
本稿方向 = [用户要比较哪项信息, 打算怎样呈现, 可自行决定的布局细节]

任务基准 = [参考稿和链接, 沿用哪些内容及阅读顺序]
组件参考 = [具体组件, 状态和位置, 喜欢的细节, 需要避免的处理]
研究方法参考 = [参考实物, 原尺寸组件, 测量或导出依据]

先在规范板放入参考原图和出处
每条规则记录 [组件和状态] / [单项变量] / [原图实测或观察] / [本稿取值] / [验收动作]
每条负面提示记录 [位置和状态] / [曾出现的问题] / [修正后应看到的效果]

建议先用真实任务内容和相邻背景制作一个 1× 样件, 确认控件轮廓, 文字和状态后再展开各稿
在空白画板独立制作, 用本稿规范的组件实例呈现相关状态, 保留证据, 人工操作和追问入口
从 Figma 导出 1× PNG, 核对阅读顺序, 图标与文字的整体居中, 边界, 换行和实际背景上的对比度
交付规范和成稿链接, 写明已核对的状态, 若某处仍需选稿, 复制同稿只改变该处的一项变量
```

例如比较顶栏底部的 1 px 白线时, 两张样件使用相同的材质, 文字和布局, 只切换这条线的可见性, 将反馈记在顶栏底边, 步骤按钮的描边另行判断
