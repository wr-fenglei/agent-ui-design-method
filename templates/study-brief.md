# 给人或 Agent 的设计任务

例如做“双记录核证”, 要让人看出两条记录属于同一订单, 可以沿用 Linear 的审阅流程, 借 Still 的窄选中行, 再把要比较的字段放成两列 [成稿](https://www.figma.com/design/scYOkdhE2byoPHW4Gk1aDL/Untitled?node-id=118-68697)

复制下框, 填好方括号就可以开始, 做多个方案时只替换“这份稿要帮人看什么”和对应的局部参考

```text
输入
用户要做什么 = [谁要在什么设备上, 根据什么做决定]
每份稿都用这些事实 = [用户请求, 实际数据, Agent 做了什么, 结果, 哪一步还要人确认]
元设计 = [底稿链接, 要沿用的内容或操作]
这份稿要帮人看什么 = [例如两次事件相隔多久, 或哪一个字段变了]
局部参考 = [原图或节点, 圈中的部件, 要放在哪里, 什么效果要避开]

请这样做
1. 先做一份规范, 放入参考原图和原尺寸组件, 写明原图是什么样, 本次取什么值
2. 用真实内容和相邻背景画一小块, 建议先按原尺寸看过, 再画整页
3. 样件不合适时, 先缩小采用范围, 或换回底稿的部件, 记下原因
4. 从空白画板画整页, 使用规范中的组件, 按用户要的格式交可编辑源稿, 再导出原尺寸图

交付
可复用的组件和规范 + 可编辑稿 + 原尺寸预览, 使用 Figma 时给出具体画板链接
选用及舍弃的部件 = [位置, 决定, 原因]
尚需选择的细节 = [如有, 两份图里只改这一项]

完成判断
能在整屏里找到证据、Agent 的解释和下一步人工操作
能从实际背景上辨认选中项和按钮, 图标与标签整组居中, 长文字显示完整
把成稿与选定参考并排看过, 说出检查的是哪个部件, 修正后重新导出
```
