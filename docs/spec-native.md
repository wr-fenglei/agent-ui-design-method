# 在 Figma 里做「组件与规范」

打开本题的一条业务记录, 先取出要比较的字段, 画一份原尺寸组件并换入第二种状态, 检查读者能否辨认差异, 再把组件实例放进首屏, 把下面的测量和样件保存在同一页的「组件与规范」分区

## 规范板交什么

每项是一张可见的 Frame、Group 或 Section, 名称使用下表的前缀和角色, 例如 `字阶/正文`, 这些是图层名称, 可显示给读者与业务相符的标题, 同类内容可以共用一列表格, 每行设为独立分组

| 分组与角色 | 在画板上呈现 | lint 核对 |
|---|---|---|
| 字阶/标题、分组、正文、操作、元数据 | 各放文字层 `字样` 与 `参数`, 例如正文写“订单载明 8 箱”, 参数写 `Inter Regular 15/22 px` | 实际字族、字形、字号、像素行高, 标题大于正文, 标题、正文和操作三档均能在成稿文字中找到 |
| 色彩/背景、正文、次文字、主操作、选中、警示、通过、分割线 | 各放原生形状 `色样` 及文字 `参数`, 写角色和六位 HEX, 半透明色补充透明度, 按下文标注实际用色 | 对照色样与参数, 核对成稿正文、大底面、主操作和选中控件的填充及透明度, 在本地状态样件中核对警示和通过的用色 |
| 几何/画板、导航、阅读区、控件、图标 | `参数` 写实际宽 × 高, 如 `176 × 36 px`, 链接到所测原生节点 | 比较节点实际宽高, 画板须链接成稿 Frame, 阅读区选实际承载证据的区域, 图标量图形或图标容器 |
| 几何/行高、内距、组距、圆角、焦点 | `参数` 写如 `行高 44 px`, 将文字链接到实测对象 | 行高读取行容器高度, 内距读取自动布局内边距, 组距读取 itemSpacing 或两个有间隔的相邻兄弟的边界, 圆角读取真实角半径, 焦点读取可见描边或零模糊扩散环 |
| 几何/检查栏、工具栏、输入 | 首屏实际有该区域时, 容器命名 `区域/检查栏`、`区域/工具栏` 或 `区域/输入`, 样件卡记录如 `302 × 40 px · 水平内距 12 px` 并链接容器 | 按区域原生宽高和一侧水平内距核验, 自由布局从非整面子层边界测量, 同时识别 Inspector、Toolbar、Composer 等常用图层名 |
| 表面/层级 | 放实际填充的 `底面` 和 `内容面`, 在文字层 `说明` 中写相邻区域怎么分组, 哪一处使用了边界, 相同底色也可用内距和文字层级区分 | 两种样片的填充与透明度均能在成稿中找到, 并有可见说明 |
| 材质/对照 | 成稿用 GLASS 或 BACKGROUND_BLUR 时, 在同一底图上放置相同形状的 `基准`、`实验`, 在 `说明` 写出本稿参数及观察到的差异 | 两节点的类型、宽高、圆角和填充一致, 原生效果不同, 实验效果参数匹配成稿, 说明含实测参数, 平面设计只需上一行 |
| 样件/导航、证据、运行、决定、复查、工具 | 每项放 1:1 本地实例、文字 `说明` 及可点击的成稿位置, 用记录中的实际或已明示模拟的字段, 讲清对象、可见状态和用途 | 对应成稿实例来自同一家族且宽高一致, 六项分别定位到成稿中承担该角色的实例, 同一组件家族可以复用 |
| 情境/业务名称 | 展示至少两处有实际数据的局部, 如“仓库清点”和“签收复查”, 各含已登记家族的原尺寸实例、业务文字、`说明` 和成稿定位 | 局部链接落在成稿实例或包含该实例的容器中, 两处的业务内容和成稿位置各异, 整屏副本不能充作局部 |

**看实际变化**　六种样件角色也可分别命名为定位、对照、进度、操作、结果、输入, 选择贴合业务的六个位置, 其中三个家族各展示两种可辨认的状态, 如待审与选中、读取成功与数据缺失、批准与暂缓, 使用 Figma 原生变体, 或将实例命名为 `状态/待审`、`状态/已审`, 检查会比较实例内的真实可见文字、图形与样式

**首屏控件用色**　`色彩/主操作` 量首屏主操作控件底色, `色彩/选中` 量首屏当前选中项底色, 可用 `样件/决定` 和 `样件/导航` 已链接的对应实例, 实例自身有底色时直接测量, 底色由子层绘制时将实际底色层分别命名为 `底色/主操作` 或 `底色/选中`

控件也可位于已链接样件实例之外, 在色彩卡增加文字层 `用色位置`, 在 Figma 选择“链接到图层”, 指向首屏中按上述方式命名的实际底色层, 提供链接时逐一核对所指图层, 例如将 `参数` 写为 `主操作 #26272B`, 将 `用色位置` 链接到“确认出库”按钮的 `底色/主操作`

**状态用色**　`色彩/警示` 和 `色彩/通过` 的 `用色位置` 链接到 `样件/…` 卡中有业务状态的本地实例或其实际呈色层, 可量底色、文字或图标填充, 测图标描边时将链接文字层命名为 `用色位置/描边`, 给状态保留可见名称或图标

状态可以只放在规范板, 例如把 `色彩/警示` 的 `用色位置/描边` 链接到“条码校验失败”样件实例中的图标, 色样和描边均使用 `#A23830`, 业务没有该状态时保留色样, 在色彩卡内加 `说明` 并写 `未使用 · 业务原因`

主操作、选中、警示和通过的色样与呈色层各使用一层可见纯色, 将填充或描边透明度与图层透明度相乘进行核对, 成稿底色计算到首屏画板, 状态色计算到本地状态实例, 色样只计算自身图层

**保留依据**　字阶、色彩、几何各选至少一个影响阅读或操作的变量, 同一张卡中放三个文字层, `来源` 写原件数值和原单位并链接到具体网页或本页「参考实物」中的图卡, `参数` 写本稿采用值, `取舍` 写任务上的原因, 例如“原表每行需同时展示三列语言, 本稿只有箱码和差异数, 收紧行高仍能读全两项”

**链接到实际对象**　样件卡链接到相应的成稿实例, 点击后可在首屏定位, 几何卡也可链接规范板中的原生组件、样件卡中的实物或名为 `测量样件` 的局部容器, 聚焦状态可以单独放在规范板, Figma 中设置“链接到图层”即可, Figmosha 可给已绘制的标注文字设置链接

```js
// position 是标注文字, placedInstance 是成稿中的实例
position.characters = '查看发货单中这项决定'
position.hyperlink = {type: 'NODE', value: placedInstance.id}

// 字样已经载入字体, 当前卡为「字阶/正文」
sample.name = '字样'
sample.fontName = {family: 'Inter', style: 'Regular'}
sample.fontSize = 15
sample.lineHeight = {unit: 'PIXELS', value: 22}
sample.characters = '仓库清点为 8 箱'
parameter.name = '参数'
parameter.characters = 'Inter Regular 15/22 px'
```

检查程序读取可见原生节点并报告出错的规则和图层, 以 1× 导出复核字色、图标视觉居中、同类字段对齐和空白, 对照实物确认取舍理由与屏幕读起来一致, 检查命令见[运行与结果](lint.md)
